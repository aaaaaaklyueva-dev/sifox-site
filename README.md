# Сайт Sifox

Статический многостраничный сайт для GitHub Pages. Страницы сделаны в Claude Design.

## Страницы
| Пункт меню | Папка |
|---|---|
| Главная | `index.html` (корень) |
| Ассистент | `assistant/` |
| Запись звонков | `call-recording/` |
| Голосовая почта | `voicemail/` |
| Исходящие поручения | `outbound/` |
| Антиспам | `antispam/` |
| Антифрод | `antifraud/` |
| Этикетки | `labels/` |

## Общие файлы (в корне)
- `sifox-menu.js` — меню для всех страниц. Пункты и ссылка «Связаться» — в блоке НАСТРОЙКИ в начале файла.
- `sifox-footer.js` — футер для всех страниц.
- `_ds/` — дизайн-система Sifox (шрифты, цвета, стили).
- `fonts/` — шрифт для меню.
- `.nojekyll` — нужен, иначе GitHub Pages не отдаёт папку `_ds/`. Не удалять.
- `404.html` — страница «не найдено».

## Как добавить новую страницу
1. Положить экспорт из Claude Design в новую папку, главный файл назвать `index.html`.
2. Подключить меню и футер: `<script src="../sifox-menu.js" defer></script>` в `<head>` и `<script src="../sifox-footer.js"></script>` перед `</body>`.
3. Добавить пункт в `LINKS` в `sifox-menu.js`.
4. Имена файлов — только латиницей, без пробелов.

## Публикация
Settings → Pages → Deploy from branch → `main` / `(root)`.
